# Interpreter Workbench: visual redress directions (no commit, app code unchanged)

Each direction folder has tokens.css, logo-mark.svg, logo-wordmark.svg, mockup-interpreter.html/.png (1280x800) and a README with a WCAG AA table. Every pair checked passes 4.5:1. The Boostlingo site research is in boostlingo-study/README.md, with citations.

## Ranking
1. **relay**: Boostlingo-adjacent. Their verified blue #1462F0, teal #82C5BF and CTA #DD3900, with Inter standing in for their paid Helvetica Now, and our own hand-off-arrows mark. It instantly reads as "built for Boostlingo" to their reviewers without claiming to be their product.
2. **clinic**: deep teal and coral on light. The most clinical and calm, but off-brand for Boostlingo.
3. **bridge**: navy, saffron, serif. Warm and human, but a serif feels more editorial than tool-like.
4. **signal**: dark console. Great for engineers, but furthest from Boostlingo's bright, light brand and from a clinical feel.

Why a new direction rather than adapting Clinic: Boostlingo's core is blue, not teal. Re-tinting Clinic would have left essentially Relay anyway, and keeping Clinic gives Andre a distinct off-brand fallback.
Caveats: Relay's accent #DD3900 with white is exactly 4.51:1. That passes AA, but keep it for buttons and labels, not long text. Teal #82C5BF is 1.96:1 on white, so it's decorative only (bars, mark), never text.
